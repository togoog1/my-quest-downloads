## Install and update

Quit the old version before updating. Your saved adventures remain separate from the app.

On Mac, open the downloaded disk image and drag **My Quest** into **Applications**. The Mac apps are ad-hoc signed and are not Apple-notarized; if macOS blocks launch, use **System Settings → Privacy & Security → Open Anyway** for this app, if offered.

On Windows, run the downloaded installer. The Windows installer is unsigned, so Windows may display a trust prompt.

Use **App updates** inside My Quest to check for new versions. Mac updates require manual replacement; Windows supports in-app installation.
