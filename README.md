# My Quest desktop downloads

[Download the latest version](https://github.com/togoog1/my-quest-downloads/releases/latest).

This repository contains desktop installers and update metadata only. Application source and private adventure packages are maintained separately.

| Computer | Installer |
|---|---|
| Windows 64-bit | `My-Quest-VERSION-win-x64.exe` |
| Mac with Apple silicon | `My-Quest-VERSION-mac-arm64.dmg` |
| Mac with an Intel processor | `My-Quest-VERSION-mac-x64.dmg` |
| Linux 64-bit | `My-Quest-VERSION-linux-x86_64.AppImage` |

Use **App updates** on the start screen or table to check for a new version. Downloads and restarts occur only when requested. Close your current table before restarting. Saved adventures are stored separately from the app and survive replacement.

Mac previews are ad-hoc signed and use manual updates: quit My Quest, drag the new app into Applications, and reopen it. They are not Apple-notarized. If macOS blocks first launch, open System Settings → Privacy & Security and use Open Anyway for My Quest, if offered. Only approve the app you downloaded from this repository. Developer ID signed and notarized releases will support automatic replacement. The original 0.2.0 Mac packages had incomplete signatures; use 0.2.1 or later. Linux in-app updates require running the AppImage itself. Older versions without an update button need one manual upgrade.

Only install releases from this repository. No GitHub account or source-code access is needed to download public releases.
